# 设计资料

本目录保存本项目的系统设计图、手机手柄参考和低模资产方案。

- `卡丁王者-小黑系统设计图-核心版.png`：手机输入 → 本地转发 → 游戏逻辑 → 画面与声音。
- `纯体感手柄-设计参考.png`：横屏、左右分区、体感转向的设计参考；实际界面以 `phone/` 为准。
- `小米SU7-低模卡丁车设计图.png`：开放驾驶舱、有驾驶员的小米 SU7 卡丁车创意。
- `中国人能飞-低模道具设计图.png`：短时飞行道具创意。
- `低模卡丁车与飞行道具-设计提示词.txt`、`标题设计提示词.txt`：生成参考的文字说明。

SU7 与飞行道具尚未制作成游戏内可用的三维资产。设计图不能直接作为三维模型导入；后续还需要建模、材质、车辆与道具逻辑适配。
